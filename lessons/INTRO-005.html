React vs Angular vs Vue

1. Visual Introduction

Think of building a food-delivery app like setting up a kitchen.

  • React = a top-quality cooking range. You buy the fridge, sink and cupboards separately (routing, forms, data fetching).
  • Angular = a fully fitted kitchen from one company. Everything is included and placed where the company decided.
  • Vue = a modular kitchen. Start with just the range, then add the official fridge and cupboards when you need them.
  SCOPE (how much comes in the box)

  small ------------------------------------------------ large
  |                         |                              |
  React                     Vue                         Angular
  (UI library)              (progressive framework)     (full framework)
  view layer only           core + official add-ons     router, forms, HTTP,
  + pick your own tools     (Vue Router, Pinia)         DI, testing, CLI built in

2. Why Do We Need It?

  • Teams waste weeks when they pick a tool by hype instead of fit.
  • Knowing the trade-offs (scope, learning curve, ecosystem) lets you explain why React was chosen.
  • Interviewers often ask “Why React and not Angular or Vue?”
Wrong
Team decision log:
"Everyone uses React, so we use React."
- no reason recorded
- nobody checked team skills
- routing/forms tools chosen in a panic later
Fixed
Team decision log:
"React: team knows JavaScript well,
 huge hiring pool, React Router 7 for routes,
 Vite 8 for tooling.
 Angular rejected: steeper learning curve.
 Vue rejected: smaller local hiring pool."

3. Core Concept

  • React: a UI library (library) from Meta. Components are JavaScript functions that return JSX. Everything else comes from the ecosystem.
  • Angular: a full framework (framework) from Google. TypeScript-first, built-in dependency injection (DI), router, forms, HTTP client and CLI.
  • Vue: a progressive framework (progressive framework) started by Evan You. HTML-like templates in single-file components (SFC, .vue files) with official router and store.
  • Scope: React smallest, Vue middle, Angular largest.
  • Learning curve: Vue usually gentlest, React moderate (needs solid JavaScript), Angular steepest (TypeScript, DI, decorators, RxJS).
  • Ecosystem: React has the largest third-party ecosystem and job market; Angular is strong in large enterprises; Vue is popular in Asia and with smaller teams.
  • All three use components (component-based architecture) and can build the same apps.

4. Syntax

The same “show a value, handle a click” in all three.

React (JSX inside JavaScript)

<button onClick={() => setCount(count + 1)}>
  Cart items: {count}
</button>

Vue (template with directives)

<button @click="count++">
  Cart items: {{ count }}
</button>

Angular (template with bindings)

<button (click)="add()">
  Cart items: {{ count() }}
</button>
React puts markup inside JavaScript (JSX). Vue and Angular put JavaScript expressions inside HTML templates.

5. Practical Example

A tiny shop cart counter. React version is a complete Vite app file; Vue and Angular versions are shown for comparison only.

React: src/App.jsx (Vite React app)

import { useState } from 'react';

const products = [
  { id: 1, name: 'Masala Chai', price: 40 },
  { id: 2, name: 'Veg Sandwich', price: 90 },
  { id: 3, name: 'Cold Coffee', price: 120 },
];

export default function App() {
  const [cart, setCart] = useState([]);

  function addToCart(product) {
    setCart([...cart, product]);
  }

  const total = cart.reduce((sum, item) => sum + item.price, 0);

  return (
    <main>
      <h1>Corner Cafe</h1>
      <ul>
        {products.map((p) => (
          <li key={p.id}>
            {p.name} – ₹{p.price}{' '}
            <button onClick={() => addToCart(p)}>Add</button>
          </li>
        ))}
      </ul>
      <p>Cart items: {cart.length} | Total: ₹{total}</p>
    </main>
  );
}

Vue: Cart.vue (comparison)

<script setup>
import { ref, computed } from 'vue'

const products = [
  { id: 1, name: 'Masala Chai', price: 40 },
  { id: 2, name: 'Veg Sandwich', price: 90 },
  { id: 3, name: 'Cold Coffee', price: 120 },
]
const cart = ref([])
const total = computed(() => cart.value.reduce((s, i) => s + i.price, 0))
</script>

<template>
  <h1>Corner Cafe</h1>
  <ul>
    <li v-for="p in products" :key="p.id">
      {{ p.name }} – ₹{{ p.price }}
      <button @click="cart.push(p)">Add</button>
    </li>
  </ul>
  <p>Cart items: {{ cart.length }} | Total: ₹{{ total }}</p>
</template>

Angular: cart.component.ts (comparison, standalone component with signals)

import { Component, computed, signal } from '@angular/core';

@Component({
  selector: 'app-cart',
  template: `
    <h1>Corner Cafe</h1>
    <ul>
      @for (p of products; track p.id) {
        <li>
          {{ p.name }} – ₹{{ p.price }}
          <button (click)="add(p)">Add</button>
        </li>
      }
    </ul>
    <p>Cart items: {{ cart().length }} | Total: ₹{{ total() }}</p>
  `,
})
export class CartComponent {
  products = [
    { id: 1, name: 'Masala Chai', price: 40 },
    { id: 2, name: 'Veg Sandwich', price: 90 },
    { id: 3, name: 'Cold Coffee', price: 120 },
  ];
  cart = signal<{ id: number; name: string; price: number }[]>([]);
  total = computed(() => this.cart().reduce((s, i) => s + i.price, 0));
  add(p: { id: number; name: string; price: number }) {
    this.cart.update((c) => [...c, p]);
  }
}
Notice: React replaces the array ([...cart, product]); Vue lets you mutate (cart.push) because its reactivity tracks changes; Angular signals use update().

9. Common Mistakes

Mistake 1: Using Vue/Angular template syntax in JSX

Wrong
<button @click={add}>
  Items: {{ count }}
</button>
// {{ count }} is an object literal in JSX
// -> "Objects are not valid as a React child"
Fixed
<button onClick={add}>
  Items: {count}
</button>

Mistake 2: Expecting React to include a router

Wrong
import { Router } from 'react';
// No such export. React has no router.
Fixed
// npm install react-router
import { BrowserRouter, Routes, Route } from 'react-router';

Mistake 3: Starting a new React project with Create React App

Wrong
npx create-react-app my-shop
# deprecated since Feb 2025
Fixed
npm create vite@latest my-shop -- --template react
cd my-shop && npm install && npm run dev

Mistake 4: Mutating state like in Vue

Wrong
cart.push(product);
setCart(cart); // same array -> React may skip re-render
Fixed
setCart([...cart, product]); // new array

Challenge

Build a React weather toggle: a button switches between °C and °F for a fixed 30 °C reading. Note which Vue feature you would have used instead.

Solution
import { useState } from 'react';

export default function App() {
  const [unit, setUnit] = useState('C');
  const celsius = 30;
  const shown = unit === 'C' ? celsius : celsius * 9 / 5 + 32;

  return (
    <div>
      <p>Delhi: {shown}°{unit}</p>
      <button onClick={() => setUnit(unit === 'C' ? 'F' : 'C')}>
        Switch to °{unit === 'C' ? 'F' : 'C'}
      </button>
    </div>
  );
}
// Vue: ref() for unit and computed() for "shown".

11. Quick Revision

  • React = UI library; Angular = full framework; Vue = progressive framework.
  • React uses JSX (markup in JS); Vue and Angular use HTML templates.
  • Learning curve: Vue gentlest, React moderate, Angular steepest.
  • React needs extra libraries for routing (React Router 7) and server rendering (a framework).
  • React updates via new state values; Vue/Angular track changes reactively (proxies / signals).
  • Start React projects with Vite, never Create React App.

12. Interview Corner

Q1. Why would you pick React over Angular?

Smaller scope so you choose your own tools, very large ecosystem and hiring pool, plain JavaScript functions as components, and skills carry over to React Native.

Q2. Is Vue a library or a framework?

Vue calls itself a progressive framework (progressive framework): a small core you can adopt gradually, plus official router (Vue Router) and store (Pinia).

Q3. What does Angular give you out of the box that React does not?

Router, forms, HTTP client, dependency injection (DI), testing setup and a CLI, all official and versioned together.

Q4. How does change detection differ?

React re-runs the component function when state is set, then compares trees (reconciliation). Vue uses reactive proxies; Angular now uses signals (and historically zone-based change detection) to update bound DOM.

Q5. Which has the steepest learning curve and why?

Angular: TypeScript, decorators, DI, modules/standalone components and RxJS are all part of the standard toolkit.

C. Must-Know Points

  1. React is maintained by Meta; Angular by Google; Vue by an independent community team led by Evan You.
  2. React = library; Angular = framework; Vue = progressive framework.
  3. React components are plain functions returning JSX.
  4. Angular is TypeScript-first; React and Vue support TypeScript optionally.
  5. React has no built-in router, form or HTTP solution.
  6. Server rendering in React comes from frameworks (Next.js, React Router framework mode).
  7. React state must be replaced, not mutated.
  8. Vite (created by Evan You) is the standard build tool for React and Vue today.

D. Interview Questions

Basic

Name one key difference between React and Angular.

React only handles the UI layer; Angular is a full framework with router, forms, HTTP and DI built in.

Intermediate

Why can Vue mutate arrays directly but React cannot?

Vue wraps state in reactive proxies that detect mutations. React compares state values with Object.is; mutating keeps the same reference so React may skip the update.

Advanced

How would you justify React for a 5-year product?

Stable core API, huge ecosystem, strong hiring market, framework options for SSR, React Native for mobile, and gradual upgrades (React 19.2 is current stable).

Tricky

“React is a framework.” True or false?

Officially false: React describes itself as a library for web and native user interfaces. Frameworks such as Next.js are built on top of it. (Lesson INTRO-006 goes deeper.)

E. Output-Based Questions

What happens? <p>{{ count }}</p> in React with count = 3
Error: Objects are not valid as a React child (found: object with keys {count}).

Inner braces create the object { count: 3 }.

What renders? {cart.length > 0 && <p>Has items</p>} with empty cart
(nothing)
What renders? {cart.length && <p>Has items</p>} with empty cart
0

React renders the number 0. Vue’s v-if does not have this trap.

F. Debugging Questions

Clicking Add does nothing on screen. Code: cart.push(p); setCart(cart);

Same array reference, so React bails out. Fix: setCart([...cart, p]).

Console: “Unknown event handler property `@click`”.

Vue syntax used in JSX. Use onClick.

G. Scenario-Based Questions

Your team of 4 knows only HTML and a little JS and must ship a shop widget in 2 weeks. Pick one.

Vue is a reasonable pick for its gentle curve; React is also fine if long-term hiring matters. Angular is the least suited for the timeline.

A company has 200 developers across 10 teams and wants one standard way to do forms and HTTP.

Angular fits: official, consistent tooling. React would need agreed library choices.
