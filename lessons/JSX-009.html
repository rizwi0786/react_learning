className

1. Visual Introduction

  • Think of name badges at a food court: "staff", "manager", "on-break". One person can wear several badges, and badges get added or removed as their status changes.
  • A CSS class is a badge for an element. In JSX you set badges with className (the JSX name for HTML's class attribute).
  • Because className takes a JavaScript value, you can build the badge list from data: add "done" when a todo is finished, "active" for the selected tab.
   data / state                 class string               CSS rules apply
 ┌────────────────────┐     ┌───────────────────────┐    ┌─────────────────────┐
 │ todo.done = true   │     │                       │    │ .todo      {...}    │
 │ todo.urgent = false│ ──► │ "todo done"           │ ─► │ .todo.done { line-  │
 │                    │     │                       │    │   through; }        │
 └────────────────────┘     └───────────────────────┘    └─────────────────────┘
     <li className={`todo ${todo.done ? 'done' : ''}`}>

2. Why Do We Need It?

  • Styling usually lives in CSS files, not inline style objects — classes keep it reusable and fast.
  • Many styles depend on state: selected, disabled, error, dark mode.
  • In vanilla JS you add/remove classes by hand (classList.toggle) and must remember to keep them in sync. In React, the class string is recalculated from state on every render, so it is always correct.
Before (vanilla JS)
// Vanilla JS: manual sync
const li = document.querySelector('#todo-1');
checkbox.addEventListener('change', () => {
  li.classList.toggle('done', checkbox.checked);
});
// Forget one toggle → UI out of sync
After (JSX)
// React: class derived from state
<li className={todo.done ? 'todo done' : 'todo'}>
  {todo.text}
</li>
// Change state → React re-renders
// → correct class every time

3. Core Concept

  • Write className, not class. (class is a reserved word in JS; className matches the DOM property element.className.)
  • className takes a string of space-separated class names: className="btn btn-primary".
  • Static class → quotes. Dynamic class → braces with any expression that produces a string.
  • Common patterns: ternary, template literal, array + filter + join, a small helper function.
  • Watch the spaces: 'btn' + 'active' becomes "btnactive".
  • Avoid putting false, undefined or "undefined" into the string.
  • In Vite, import './App.css' adds global CSS. import styles from './Card.module.css' gives CSS Modules (locally scoped class names): className={styles.card}.
  • On your own components, className is just a normal prop — the component must pass it on to a DOM element for it to work.
  • The third-party package clsx (npm i clsx) is a popular helper for conditional classes; it is not part of React.

4. Syntax

// 1. Static
<button className="btn">Order</button>

// 2. Ternary — choose one of two
<span className={isOpen ? 'badge open' : 'badge closed'}>…</span>

// 3. Template literal — base + optional extra
<li className={`todo ${done ? 'done' : ''}`}>…</li>

// 4. Array + filter + join — many optional classes
<button
  className={['btn', isPrimary && 'btn-primary', isLoading && 'loading']
    .filter(Boolean)
    .join(' ')}
/>

// 5. Small helper (no library)
const cx = (...names) => names.filter(Boolean).join(' ');
<div className={cx('card', selected && 'card--selected')} />

// 6. CSS Modules (Vite supports *.module.css)
import styles from './Card.module.css';
<div className={styles.card} />
<div className={`${styles.card} ${styles.highlight}`} />

// 7. Forwarding className in your own component
function Card({ className, children }) {
  return <div className={cx('card', className)}>{children}</div>;
}

5. Practical Example

A food-delivery menu with category tabs and dish cards. In a Vite React app create src/App.css and replace src/App.jsx:

/* src/App.css */
.tabs { display: flex; gap: 8px; margin-bottom: 12px; }
.tab { padding: 6px 12px; border: 1px solid #ccc; border-radius: 999px; background: #fff; cursor: pointer; }
.tab.active { background: #e85d04; color: #fff; border-color: #e85d04; }

.dish { padding: 10px; border: 1px solid #ddd; border-radius: 8px; margin-bottom: 8px; }
.dish.veg { border-left: 4px solid #2b9348; }
.dish.non-veg { border-left: 4px solid #d00000; }
.dish.sold-out { opacity: 0.5; }
.dish.selected { outline: 2px solid #e85d04; }
// src/App.jsx
import { useState } from 'react';
import './App.css';

const DISHES = [
  { id: 1, name: 'Paneer Butter Masala', veg: true, category: 'mains', soldOut: false },
  { id: 2, name: 'Chicken Biryani', veg: false, category: 'mains', soldOut: false },
  { id: 3, name: 'Gulab Jamun', veg: true, category: 'desserts', soldOut: true },
  { id: 4, name: 'Masala Chai', veg: true, category: 'drinks', soldOut: false },
];

const CATEGORIES = ['all', 'mains', 'desserts', 'drinks'];

// Tiny helper: keeps only truthy names, joins with spaces
function cx(...names) {
  return names.filter(Boolean).join(' ');
}

export default function App() {
  const [category, setCategory] = useState('all');
  const [selectedId, setSelectedId] = useState(null);

  const visible = DISHES.filter(
    (d) => category === 'all' || d.category === category
  );

  return (
    <main>
      <nav className="tabs">
        {CATEGORIES.map((c) => (
          <button
            key={c}
            className={`tab ${c === category ? 'active' : ''}`.trim()}
            onClick={() => setCategory(c)}
          >
            {c}
          </button>
        ))}
      </nav>

      {visible.map((d) => (
        <div
          key={d.id}
          className={cx(
            'dish',
            d.veg ? 'veg' : 'non-veg',
            d.soldOut && 'sold-out',
            d.id === selectedId && 'selected'
          )}
          onClick={() => setSelectedId(d.id)}
        >
          {d.name} {d.soldOut && '(sold out)'}
        </div>
      ))}
    </main>
  );
}

8. Real-World Application

  • Shopping: className={cx('product', outOfStock && 'muted', onSale && 'sale')}.
  • Todo app: strike-through for completed items with className={todo.done ? 'done' : undefined}.
  • Chat: className={msg.from === me ? 'bubble mine' : 'bubble theirs'} to align bubbles left/right.
  • Forms: className={error ? 'input input--error' : 'input'}.
  • Utility CSS (e.g. Tailwind): very long className strings, often managed with clsx — same rules apply.

9. Common Mistakes

Mistake 1: Using class instead of className

Wrong
<div class="card">Pizza</div>
// Works, but React warns in dev:
// Invalid DOM property `class`.
// Did you mean `className`?
Fixed
<div className="card">Pizza</div>

Mistake 2: Missing space when joining

Wrong
<button className={'btn' + (active ? 'active' : '')}>
// → "btnactive"
Fixed
<button className={'btn' + (active ? ' active' : '')}>
// → "btn active"
// or: className={`btn ${active ? 'active' : ''}`}

Mistake 3: && giving false or "false"

Wrong
<li className={done && 'done'}>
// done = false → React warns:
// Received `false` for a non-boolean attribute

<li className={`todo ${done && 'done'}`}>
// → "todo false"
Fixed
<li className={done ? 'done' : undefined}>
// undefined → no class attribute at all

<li className={`todo ${done ? 'done' : ''}`}>
// → "todo " (harmless trailing space)

Mistake 4: Component ignores className

Wrong
function Card({ children }) {
  return <div className="card">{children}</div>;
}
<Card className="featured">Dune</Card>
// "featured" is silently dropped
Fixed
function Card({ className = '', children }) {
  return (
    <div className={`card ${className}`.trim()}>
      {children}
    </div>
  );
}

11. Quick Revision

  • JSX uses className, not class.
  • Value is one space-separated string.
  • Static → "a b"; dynamic → {expression}.
  • Patterns: ternary, template literal, [...].filter(Boolean).join(' '), helper cx().
  • Check spaces and avoid false/undefined ending up in the string.
  • CSS Modules: import styles from './X.module.css' → styles.name.
  • Custom components must forward className themselves.

12. Interview Corner

Why does JSX use className?

JSX is JavaScript, where class is a reserved keyword, and React props follow DOM property names — the DOM property for the class attribute is element.className.

How do you apply classes conditionally?

Compute a string: ternary (a ? 'x' : 'y'), template literal, an array filtered for truthy values and joined, or a helper like the third-party clsx.

What happens if you pass className={false}?

React omits the attribute and logs a development warning ("Received false for a non-boolean attribute className"). Use undefined or an empty string instead.

What do CSS Modules solve?

Class name collisions. Each *.module.css class is renamed to a unique local name at build time (Vite supports this out of the box), so .title in two files never clashes.

className vs style — when to use which?

className for reusable, theme-able styles defined in CSS (supports hover, media queries). style for truly dynamic per-element values, e.g. a progress bar width.

A. Concept in 30 Seconds

className sets CSS classes in JSX. It takes one space-separated string, so you can build it from state with a ternary, template literal, or filter(Boolean).join(' '). React re-computes it on every render, so classes always match the data.

B. Important Syntax

<div className="card" />                                   // static
<div className={ok ? 'card ok' : 'card'} />                // ternary
<div className={`card ${ok ? 'ok' : ''}`} />               // template literal
<div className={['card', ok && 'ok'].filter(Boolean).join(' ')} />
import styles from './Card.module.css';
<div className={styles.card} />                            // CSS Module
import clsx from 'clsx';            // third-party package
<div className={clsx('card', { ok: isOk })} />

C. Must-Know Points

  1. className replaces class in JSX.
  2. It is a single string with spaces between names.
  3. Use braces for dynamic values.
  4. Mind the spaces when concatenating.
  5. false as className triggers a dev warning; undefined simply omits it.
  6. ${cond && 'x'} inside a template literal can produce the text "false".
  7. filter(Boolean) removes false, null, undefined, '', 0.
  8. Vite supports plain CSS imports and *.module.css CSS Modules.
  9. Components must forward className to a DOM element.
  10. clsx is a third-party helper, not part of React.

D. Interview Questions

Basic

How do you add two classes to an element?

className="price big" — separate them with a space.

Intermediate

Write a conditional class without a library.

className={['tab', active && 'active'].filter(Boolean).join(' ')}.

Does class work at all in React?

React DOM still sets it, but logs a dev warning suggesting className. Always use className.

Advanced

How do CSS Modules change class names?

The build tool rewrites each class to a unique scoped name (e.g. _card_1x2y3) and the imported styles object maps your names to the generated ones.

Tricky

What class does className={`btn ${undefined}`} produce?

"btn undefined" — template literals turn undefined into the text "undefined".

Why might <Card className="wide" /> have no effect?

Card is your component; className is just a prop. If Card doesn't pass it to an inner DOM element, nothing happens.

F. Debugging Questions

Bug 1

<button className={"btn" + selected ? "selected" : ""}>Tea</button>
Show answer

Operator precedence: + runs before ?:, so it becomes ("btn" + selected) ? "selected" : "" → always "selected". Fix: "btn" + (selected ? " selected" : "").

Bug 2

import styles from './Card.module.css';
<div className="styles.card" />
Show answer

Quoted, so the class is literally styles.card. Use className={styles.card}.

Bug 3

<div className={isOpen && 'open'} />
// Console: Received `false` for a non-boolean attribute `className`
Show answer

Use className={isOpen ? 'open' : undefined}.

Challenge 2: Write your own cx

Write cx that accepts strings and objects: cx('a', { b: true, c: false }) → "a b".

Show solution 
function cx(...args) {
  return args
    .flatMap((a) =>
      a && typeof a === 'object'
        ? Object.keys(a).filter((k) => a[k])
        : [a]
    )
    .filter(Boolean)
    .join(' ');
}
cx('a', { b: true, c: false }); // "a b"
