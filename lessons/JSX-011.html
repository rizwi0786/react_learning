Inline styles

1. Visual Introduction

  • Think of a restaurant order slip: "Spice: medium, Size: large, Extra: cheese". Each line is a name and a value.
  • In JSX, inline styles are that slip written as a JavaScript object (a style object): { color: 'red', fontSize: 18 }.
  • CSS names with dashes become one joined-up word with capitals (camelCase): font-size → fontSize.
   style={{ backgroundColor: 'gold', fontSize: 18 }}
         │└──────────────────┬──────────────────┘│
         │          JS object (the order slip)   │
         └── outer { } = "a JS value comes next" ┘

   CSS (string)                     JSX style object
   ─────────────────────────        ───────────────────────────
   background-color: gold;    ──►   backgroundColor: 'gold'
   font-size: 18px;           ──►   fontSize: 18        (px added)
   line-height: 1.5;          ──►   lineHeight: 1.5     (no unit)

2. Why Do We Need It?

  • Some styles depend on data: a progress bar width, a rating colour, a user-picked theme colour.
  • A JS object can be computed, merged and passed around like any value.
  • For fixed looks, CSS classes (className) are still better. Inline style is for dynamic values.
Before (vanilla JS)
// Vanilla JS: build CSS text by hand
const bar = document.createElement('div');
bar.style.cssText =
  'height: 8px; background-color: green; width: '
  + percent + '%;';
// easy to miss a ; or a unit
document.body.appendChild(bar);
After (JSX style object)
// JSX: a plain object, values from JS
<div
  style={{
    height: 8,
    backgroundColor: 'green',
    width: `${percent}%`,
  }}
/>

3. Core Concept

  • style takes an object, never a string. A string throws an error.
  • {{ }} is not special syntax: outer braces = JS expression, inner braces = object literal.
  • Property names are camelCase: marginTop, borderRadius, zIndex.
  • Vendor prefixes start with a capital, except ms: WebkitLineClamp, msTransform.
  • Numbers get px added automatically for size properties: padding: 12 → 12px.
  • Unitless properties keep the plain number: opacity, zIndex, lineHeight, fontWeight, flex, flexGrow.
  • Other units need a string: '50%', '2rem', '100vh'.
  • null, undefined or booleans as a value → that property is skipped.
  • CSS variables (custom properties) keep their dashes in quotes: { '--brand': 'tomato' }.
  • Not possible inline: :hover, ::before, media queries, keyframes. !important is not supported in a style object. Use CSS for these.

4. Syntax

// 1. Inline object
<p style={{ color: 'tomato', fontSize: 18 }}>Hot deal!</p>

// 2. Object in a variable (reusable)
const badge = { padding: '2px 8px', borderRadius: 12, backgroundColor: '#e7f6ec' };
<span style={badge}>Veg</span>

// 3. Dynamic values
<div style={{ width: `${progress}%` }} />
<p style={{ color: temp > 30 ? 'crimson' : 'steelblue' }}>{temp}°C</p>

// 4. Merge: later keys win
<span style={{ ...badge, backgroundColor: '#fde8e8' }}>Non-veg</span>

// 5. Units
{ margin: 0 }          // "0"
{ marginTop: 16 }      // "16px"
{ lineHeight: 1.4 }    // "1.4" (unitless)
{ width: '50%' }       // string for non-px units

// 6. Vendor prefix and CSS variable
{ WebkitLineClamp: 2 }
{ '--accent': 'orange', color: 'var(--accent)' }

// 7. Skip a property conditionally
{ fontWeight: isNew ? 700 : undefined }

5. Practical Example

A movie rating list with a coloured score bar and a "now showing" badge. In a Vite React app, replace src/App.jsx:

// src/App.jsx
import { useState } from 'react';

const movies = [
  { id: 1, title: 'Inside Out 2', rating: 8.1, showing: true },
  { id: 2, title: 'Dune: Part Two', rating: 9.0, showing: false },
  { id: 3, title: 'The Room', rating: 3.4, showing: true },
];

// Shared style objects live outside the component
const card = {
  border: '1px solid #ddd',
  borderRadius: 10,          // → 10px
  padding: 12,               // → 12px
  marginBottom: 10,
  maxWidth: 320,
};

const badge = {
  display: 'inline-block',
  marginLeft: 8,
  padding: '1px 8px',
  borderRadius: 999,
  fontSize: 12,
  backgroundColor: '#e7f6ec',
  color: '#1b6b35',
};

function scoreColor(r) {
  if (r >= 8) return 'seagreen';
  if (r >= 5) return 'orange';
  return 'crimson';
}

function MovieCard({ movie, big }) {
  return (
    <div style={card}>
      <strong style={{ fontSize: big ? 20 : 16, lineHeight: 1.3 }}>
        {movie.title}
      </strong>
      {movie.showing && <span style={badge}>Now showing</span>}

      {/* Track + dynamic-width fill */}
      <div style={{ height: 8, backgroundColor: '#eee', borderRadius: 4, marginTop: 8 }}>
        <div
          style={{
            width: `${movie.rating * 10}%`,
            height: '100%',
            borderRadius: 4,
            backgroundColor: scoreColor(movie.rating),
          }}
        />
      </div>
      <small style={{ color: scoreColor(movie.rating), fontWeight: 600 }}>
        {movie.rating} / 10
      </small>
    </div>
  );
}

export default function App() {
  const [big, setBig] = useState(false);
  return (
    <main style={{ fontFamily: 'sans-serif', padding: 16 }}>
      <button onClick={() => setBig(!big)} style={{ marginBottom: 12 }}>
        {big ? 'Smaller titles' : 'Bigger titles'}
      </button>
      {movies.map((m) => (
        <MovieCard key={m.id} movie={m} big={big} />
      ))}
    </main>
  );
}

7. Execution Flow

 1. Vite compiles  <div style={{ width: `${r * 10}%`, height: 8 }} />
      ──► jsx("div", { style: { width: "81%", height: 8 } })
        │
        ▼
 2. React DOM reads the style object key by key
        │
        ├─ width: "81%"   string → used as-is
        ├─ height: 8      number, not unitless → "8px"
        └─ lineHeight: 1.3 number, unitless   → "1.3"
        │
        ▼
 3. Sets each one on the element:  el.style.width = "81%" ...
    (CSS variables like '--accent' use el.style.setProperty)
        │
        ▼
 4. Click "Bigger titles" → setBig(true) → re-render
        │
        ▼
 5. React compares old vs new style object and updates ONLY
    the changed keys (fontSize 16px → 20px)

8. Real-World Application

  • Food delivery: order tracker bar, width: `${step / 4 * 100}%`.
  • Weather app: temperature text colour from cold blue to hot red.
  • Chat app: user-chosen bubble colour from settings: backgroundColor: user.color.
  • Shop: product image positioned by drag (transform: `translate(${x}px, ${y}px)`).
  • Theming: set a CSS variable once, style={{ '--brand': theme.brand }}, and let CSS classes use var(--brand).
Rule of thumb: fixed look → CSS class, value from data → inline style (or a CSS variable set inline).

9. Common Mistakes

Mistake 1: Passing a CSS string

Wrong
<p style="color: red; font-size: 18px">Sale</p>
// Error: The `style` prop expects a mapping
// from style properties to values, not a string.
Fixed
<p style={{ color: 'red', fontSize: 18 }}>Sale</p>

Mistake 2: Dashed property names

Wrong
<div style={{ 'background-color': 'gold' }} />
// Dev warning: Unsupported style property
// background-color. Did you mean backgroundColor?
// (it may seem to work, but don't rely on it)

<div style={{ background-color: 'gold' }} />
// Syntax error (minus sign)
Fixed
<div style={{ backgroundColor: 'gold' }} />

Mistake 3: Numbers where px is not wanted

Wrong
<div style={{ width: 50 }} />
// wanted 50%, got 50px

<p style={{ fontSize: '18' }}>Hi</p>
// string "18" has no unit → ignored by browser
Fixed
<div style={{ width: '50%' }} />

<p style={{ fontSize: 18 }}>Hi</p>
// or fontSize: '18px'

Mistake 4: Trying :hover inline

Wrong
<button style={{ ':hover': { color: 'red' } }}>
  Buy
</button>
// Not a CSS property: silently ignored
Fixed
/* App.css */
.buy:hover { color: red; }

// App.jsx
import './App.css';
<button className="buy">Buy</button>

11. Quick Revision

  • style = object, not string.
  • {{ }} = expression braces + object braces.
  • camelCase names; CSS variables keep '--name' in quotes.
  • Numbers → px, except unitless (opacity, zIndex, lineHeight, fontWeight, flex).
  • Other units → strings: '50%', '2rem'.
  • No :hover, media queries or !important inline.
  • Use inline style for data-driven values; classes for everything else.

12. Interview Corner

Why double curly braces in style={{ color: 'red' }}?

The outer pair says "JS expression here"; the inner pair is the object literal. It is just an object passed as a prop.

What does { marginTop: 10, opacity: 0.5 } produce?

margin-top: 10px; opacity: 0.5. opacity is unitless, so no px.

Inline styles vs CSS classes: when to choose which?

Classes for fixed designs, hover/focus states and media queries (cacheable, cleaner). Inline styles for values that change with data or state. A middle path: set a CSS variable inline and use it in a class.

How do you write a vendor-prefixed property?

Capital first letter: WebkitTransition, MozAppearance. The ms prefix is lowercase: msTransition.

A. Concept in 30 Seconds

In JSX, style takes a JavaScript object with camelCase keys. Numbers become pixels (except unitless properties like opacity). Use it for dynamic values; use CSS classes for hover, media queries and fixed designs.

B. Important Syntax

<p style={{ color: 'red', fontSize: 18 }}>Hi</p>
const s = { marginTop: 8 };  <p style={s}>Hi</p>
<p style={{ ...s, color: 'blue' }}>Hi</p>
<div style={{ width: `${pct}%` }} />
<div style={{ '--brand': 'teal' }} />
<div style={{ WebkitLineClamp: 2 }} />

C. Must-Know Points

  • Object, not string — a string throws.
  • Keys are camelCase.
  • Numeric values get px unless the property is unitless.
  • Unitless examples: opacity, zIndex, lineHeight, fontWeight, flex, flexGrow, order.
  • null/undefined/boolean values skip the property.
  • Spread merges objects; later keys win.
  • CSS variables: quoted keys starting with --.
  • No pseudo-classes, pseudo-elements, media queries, keyframes or !important.
  • Inline style beats most class rules (higher specificity).
  • Define constant style objects outside the component to keep the code tidy.

D. Interview Questions

Basic

How do you write background-color in JSX?

backgroundColor.

Intermediate

What is { lineHeight: 2 } vs { lineHeight: '2px' }?

The first is unitless (2 × font size). The second is a fixed 2 pixels — usually a bug.

Advanced

How does React update styles on re-render?

It compares the previous and next style objects and sets or clears only the keys that changed. Removed keys are reset to empty.

How do you combine inline values with hover effects?

Set a CSS variable inline (style={{ '--c': color }}) and write .btn:hover { background: var(--c) } in CSS.

Tricky

Does style={{ color: 'red !important' }} work?

No. !important is not supported in a style object; the browser rejects that value and the colour is not applied. Use a CSS class if you truly need it.

E. Output-Based Questions

What CSS text appears? <div style={{ padding: 10, zIndex: 3, width: '50%' }} /> 
padding: 10px; z-index: 3; width: 50%;
What colour? style={{ ...{ color: 'red' }, color: 'blue' }}

Blue — the later key wins.

What happens? style={{ color: isSale && 'red' }} when isSale is false

Value is false → property skipped → default text colour.

F. Debugging Questions

App crashes with "The `style` prop expects a mapping…". Why?

A CSS string was passed to style. Convert it to an object.

Width is 75px instead of 75%: style={{ width: 75 }}

Numbers mean pixels. Write width: '75%'.

fontSize: '20' has no effect.

A string without a unit is invalid CSS for font-size. Use 20 or '20px'.

G. Scenario-Based Questions

Each chat user picks a bubble colour. How do you style the bubble?

Fixed layout in a class; colour inline: <div className="bubble" style={{ backgroundColor: user.color }}>.

Product cards need a hover shadow and a stock-level border colour.

Hover shadow in CSS (.card:hover); border colour inline or through a CSS variable set inline.
